# GitHub Pages

`index.html` here is the published site, copied from `web/site/` by `make site`.

To turn it on: **Settings → Pages → Source: Deploy from a branch →
Branch: `main`, folder: `/docs` → Save.**

The URL will be `https://aakanksha-singh-hub.github.io/pramana/`.

Requires the repository to be public (or GitHub Pro).
